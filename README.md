# Computer Vision – Day 1

## 25 Python + OpenCV Coding Questions

This repository contains my Day 1 Computer Vision assignment implemented
using Python, OpenCV, NumPy, and Matplotlib.

The notebook covers fundamental concepts of image processing including
image handling, pixel operations, image representation, sampling,
quantization, and basic geometric operations.

---

## Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- Google Colab
- Jupyter Notebook

---

## Topics Covered

### 1. Basic Image Handling

- Read and display an image
- Check image loading
- Image height, width, and channels
- Total number of pixels
- Image data type
- Save an image with a different filename
- Read image in grayscale
- Convert color image to grayscale
- Display image using Matplotlib
- Resize image to 50%

### 2. Pixel & Image Representation

- Access pixel values
- Modify pixel values
- Read BGR values
- Split BGR channels
- Merge image channels
- Minimum and maximum intensity
- Mean intensity
- Mean and standard deviation
- Create constant grayscale image
- Create grayscale intensity ramp

### 3. Sampling, Quantization & Geometric Operations

- 4-bit image quantization
- 2-bit image quantization
- Image downsampling
- Region of Interest (ROI)
- 90-degree image rotation
